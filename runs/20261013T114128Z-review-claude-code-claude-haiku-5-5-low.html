None.

- Fix sketch: either have the mode write re-read preferences under `sendMutex` before sending (a `getPreferences` immediately before the PUT), or change the backend so `displayUnit` is optional on PUT, as `sessionView` already is. The second option removes the clobber entirely.

### Summary

- **Error return:** `chooseSessionView` checks the unit before sending, and a failed load refuses the write (`error(...)` inside `runCatching`) rather than sending a guessed unit. The revert path is handled by `WriteFailureOutcome`.

The main gap is that a response missing `sessionView` is silently decoded as Focus and adopted as the confirmed value.
